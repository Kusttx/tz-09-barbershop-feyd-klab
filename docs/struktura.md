# Что где лежит и за что отвечает

Путеводитель по репозиторию `tz-09-barbershop-feyd-klab`. Пригодится на защите, когда спросят «покажите, где это сделано».

## Страницы сайта (корень)

Лежат в корне, потому что Vercel публикует сайт с `index.html` в корне.

| Файл | Что это |
|---|---|
| `index.html` | Главная: акция −20 %, свободное время на сегодня, услуги, 4 мастера, 6 работ, сертификаты |
| `services.html` | Таблица цен по уровням мастеров, сертификаты (якорь `#gift`), ссылка на прайс PDF |
| `masters.html` | 8 мастеров с фильтром по уровню, кнопка «Записаться к мастеру» |
| `works.html` | Галерея 24 работ с фильтром: фейд, кроп, классика, борода |
| `style-quiz.html` | Тест «Форма лица» из 4 вопросов, 3 стрижки, промокод FIRST20. Сюда ведёт автоответ из Instagram |
| `contacts.html` | Запись: календарь на 14 дней, слоты по часу, форма, телефон, мессенджеры, карта |
| `thanks.html` | «Вы записаны»: номер записи, дата и время, кнопка «Добавить в календарь» |
| `privacy.html` | Политика обработки персональных данных по 152-ФЗ |
| `404.html` | Страница «не найдено» |
| `robots.txt`, `sitemap.xml` | Подсказки поисковикам, нужны для оценки SEO в Lighthouse |

В `<head>` каждой страницы — тег Google Analytics с идентификатором `G-LKT0RQ9B2E`, заголовок, описание и превью для соцсетей.

## Код

| Файл | За что отвечает |
|---|---|
| `css/style.css` | Весь внешний вид: фирменные цвета, шрифты, адаптив под телефон |
| `js/analytics.js` | **Все события GA4.** Единственное место с `gtag('event', …)`. Ловит клики по кнопкам с атрибутом `data-event` и отправляет событие с параметрами. Не пропускает имя, телефон и e-mail |
| `js/main.js` | Меню на телефоне, сохранение UTM-меток в `sessionStorage`, фильтры мастеров и работ, массив занятых слотов, «Свободно сегодня» на главной |
| `js/form.js` | Запись: рисует календарь и слоты, проверяет поля, показывает ошибки, отправляет заявку в Apps Script, после ответа «ok» шлёт `generate_lead` и открывает «Спасибо» |
| `js/quiz.js` | Тест «Форма лица» и копирование промокода |
| `js/thanks.js` | Показывает номер записи и делает файл `.ics` для календаря |
| `apps-script/Code.gs` | Приёмник заявок: функция `doPost` проверяет поля, не пускает дубли и пишет строку в лист `leads`. Функция `setupSheet` один раз настроила лист |
| `apps-script/appsscript.json` | Настройки проекта Apps Script: часовой пояс Москва, доступ к веб-приложению |

## Частые вопросы на защите

- **«Где отправляется generate_lead?»** — `js/form.js`, после ответа приёмника `{"ok": true}`; сам вызов `gtag` — в `js/analytics.js`.
- **«Как метки доходят до таблицы?»** — `js/main.js` сохраняет их из адреса в `sessionStorage`, `js/form.js` кладёт в скрытые поля формы, `apps-script/Code.gs` пишет в столбцы `utm_*`.
- **«Где заданы занятые слоты?»** — массив `BUSY_SLOTS` в `js/main.js`.
- **«Что будет при повторной заявке?»** — `Code.gs` ищет `request_id` в таблице и возвращает ошибку, вторая строка не появляется.
